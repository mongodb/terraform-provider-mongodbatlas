# Resource: mongodbatlas_cluster_adaptive_settings

`mongodbatlas_cluster_adaptive_settings` provides a resource for managing Adaptive Settings overrides for one MongoDB Atlas cluster.

-> **NOTE:** Set `adaptive_settings_overrides` with `jsonencode`. The initial supported keys are `OVERLOAD_PROTECTION` and `SEARCH_OVERLOAD_PROTECTION`. Removing a key from the configured object resets that override. Destroying this resource resets all overrides to Atlas-managed defaults and does not delete the cluster.

## Example Usages

```terraform
resource "mongodbatlas_cluster_adaptive_settings" "this" {
  project_id   = var.project_id
  cluster_name = var.cluster_name
  adaptive_settings_overrides = jsonencode({
    OVERLOAD_PROTECTION        = var.overload_protection_enabled
    SEARCH_OVERLOAD_PROTECTION = var.search_overload_protection_enabled
  })
}

data "mongodbatlas_cluster_adaptive_settings" "this" {
  project_id   = mongodbatlas_cluster_adaptive_settings.this.project_id
  cluster_name = mongodbatlas_cluster_adaptive_settings.this.cluster_name
}
```

## Schema

### Required

- `cluster_name` (String) Human-readable label that identifies the cluster.
- `project_id` (String) Unique 24-hexadecimal digit string that identifies your project, also known as `groupId` in the official documentation.

### Optional

- `adaptive_settings_overrides` (String) JSON-encoded map of customer-specified Adaptive Settings overrides. Use `jsonencode` to configure this attribute. Each supported entry that you specify takes precedence over the corresponding Atlas-managed default.

### Read-Only

- `effective_adaptive_settings` (String) JSON-encoded map of the effective Adaptive Settings currently applied to your cluster, based on your overrides and Atlas-managed defaults. Atlas-managed defaults can vary by MongoDB version.

## Import

Import cluster Adaptive Settings by using the project ID and cluster name in the format `PROJECT_ID/CLUSTER_NAME`, for example:

```shell
terraform import mongodbatlas_cluster_adaptive_settings.this 0123456789abcdef01234567/Cluster0
```
