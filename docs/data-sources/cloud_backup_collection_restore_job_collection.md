# Data Source: mongodbatlas_cloud_backup_collection_restore_job_collection

`mongodbatlas_cloud_backup_collection_restore_job_collection` describes the restore state of one collection in a collection restore job.

To use this data source, the requesting Service Account or API Key must have the Backup Manager or Project Owner role.

~> **Note:** This data source returns no collection state while the job is `INITIALIZING`. Collection states exist after the job enters `IN_PROGRESS`.

## Example Usage

The following example lists per-collection restore state for a job, then reads one collection by `source_namespace`. When `source_namespace` is omitted, the example defaults to the last namespace from the plural data source.

```terraform
data "mongodbatlas_cloud_backup_collection_restore_job_collections" "this" {
  project_id   = var.project_id
  cluster_name = var.cluster_name
  job_id       = local.job_id
}

locals {
  source_namespace = coalesce(var.source_namespace, data.mongodbatlas_cloud_backup_collection_restore_job_collections.this.results[length(data.mongodbatlas_cloud_backup_collection_restore_job_collections.this.results) - 1].source_namespace)
}

data "mongodbatlas_cloud_backup_collection_restore_job_collection" "this" {
  project_id       = var.project_id
  cluster_name     = var.cluster_name
  job_id           = local.job_id
  source_namespace = local.source_namespace
}
```

## Schema

### Required

- `cluster_name` (String) Human-readable label that identifies the cluster with the collection restore job you want to return.
- `job_id` (String) Unique 24-hexadecimal digit string that identifies the collection restore job.
- `project_id` (String) Unique 24-hexadecimal digit string that identifies your project, also known as `groupId` in the official documentation.
- `source_namespace` (String) Source namespace that identifies the collection to return (e.g. `db.collection`).

### Read-Only

- `effective_target_namespace` (String) Actual target namespace after restore (e.g. after conflict rename).
- `index_status` (Attributes) Index build status for a collection within a restore job. (see [below for nested schema](#nestedatt--index_status))
- `restored_documents` (Number) Number of documents restored so far.
- `state` (String) Current state of this collection within the restore job.
- `target_namespace` (String) Requested target namespace for the restored collection.
- `total_documents` (Number) Total document count for this collection.

### Nested Schema for `index_status`

Read-Only:

- `error_message` (String) Error message if index build failed.
- `failed_indexes` (List of String) List of index specifications that failed to build (up to 64 items).
- `state` (String) Index build state indicating the status of index creation during or after a restore operation.

For more information see: [MongoDB Atlas - Restore from Selected Databases and Collections](https://www.mongodb.com/docs/atlas/backup/cloud-backup/restore-from-db-coll/) Documentation.
