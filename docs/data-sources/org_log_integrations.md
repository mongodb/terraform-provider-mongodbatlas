# Data Source: mongodbatlas_org_log_integrations

`mongodbatlas_org_log_integrations` describes all log integrations configured at the organization level. Currently, OpenTelemetry is the only supported integration type.

To use this data source, the requesting Service Account or API Key must have the Organization Owner role.

## Example Usage

```terraform
data "mongodbatlas_org_log_integrations" "example" {
  org_id     = mongodbatlas_org_log_integration.example.org_id
  depends_on = [mongodbatlas_org_log_integration.example]
}

output "org_log_integration_ids" {
  value = [for r in data.mongodbatlas_org_log_integrations.example.results : r.integration_id]
}
```
